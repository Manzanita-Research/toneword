### Integration Issues (1 broken connection + 2 CI bugs)

1. **`background.png` missing** — `distribution.xml.template` references it, but `plugin/packaging/resources/` only has EULA and README. Will break `productbuild` when signing is enabled.

2. **Invalid GitHub Actions versions** — `actions/checkout@v6`, `actions/upload-artifact@v6`, `actions/download-artifact@v7` do not exist. Should all be `@v4`. CI will fail at first step.

3. **EQ curve sample rate stale** — `EQCurvePanel` initialized with `getSampleRate()` at construction but `setSampleRate()` never called after. Curve inaccurate at 48kHz/96kHz sessions. Low priority (Logic defaults to 44.1kHz).
