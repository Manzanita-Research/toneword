After the pluginval and auval steps in the existing workflow (created by Plan 04-01), add the following steps. All signing/notarization steps MUST be conditional on secrets presence so the pipeline works without an Apple Developer account.

**Certificate import step:**
```yaml
- name: Import Certificates (macOS)
  if: ${{ secrets.DEV_ID_APP_CERT != '' }}
  uses: sudara/basic-macos-keychain-action@v1
  id: keychain
  with:
    dev-id-app-cert: ${{ secrets.DEV_ID_APP_CERT }}
    dev-id-app-password: ${{ secrets.DEV_ID_APP_PASSWORD }}
    dev-id-installer-cert: ${{ secrets.DEV_ID_INSTALLER_CERT }}
    dev-id-installer-password: ${{ secrets.DEV_ID_INSTALLER_PASSWORD }}
```

**Codesign step** (conditional on keychain success):
```yaml
- name: Codesign
  if: ${{ steps.keychain.outcome == 'success' }}
  timeout-minutes: 5
  run: |
    codesign --force --keychain ${{ steps.keychain.outputs.keychain-path }} -s "${{ secrets.DEVELOPER_ID_APPLICATION }}" -v "${{ env.VST3_PATH }}" --deep --strict --options=runtime --timestamp
    codesign --force --keychain ${{ steps.keychain.outputs.keychain-path }} -s "${{ secrets.DEVELOPER_ID_APPLICATION }}" -v "${{ env.AU_PATH }}" --deep --strict --options=runtime --timestamp
    codesign --force --keychain ${{ steps.keychain.outputs.keychain-path }} -s "${{ secrets.DEVELOPER_ID_APPLICATION }}" -v "${{ env.STANDALONE_PATH }}" --deep --strict --options=runtime --timestamp
```

**Custom icons step:**
```yaml
- name: Add Custom Icons
  if: ${{ steps.keychain.outcome == 'success' }}
  working-directory: plugin
  run: |
    sips -i packaging/pamplejuce.icns
    DeRez -only icns packaging/pamplejuce.icns > /tmp/icons
    Rez -a /tmp/icons -o "${{ env.VST3_PATH }}/Icon"$'\r'
    Rez -a /tmp/icons -o "${{ env.AU_PATH }}/Icon"$'\r'
    SetFile -a C "${{ env.VST3_PATH }}"
    SetFile -a C "${{ env.AU_PATH }}"
```

Note: Use `packaging/pamplejuce.icns` since icon file exists. If project has its own icon, update the reference.

**Package and notarize step:**
```yaml
- name: Package and Notarize
  if: ${{ steps.keychain.outcome == 'success' }}
  timeout-minutes: 10
  working-directory: plugin
  run: |
    pkgbuild --identifier "${{ env.BUNDLE_ID }}.vst3.pkg" --version ${{ env.VERSION }} --component "${{ env.VST3_PATH }}" --install-location "/Library/Audio/Plug-Ins/VST3" "packaging/${{ env.PRODUCT_NAME }}.vst3.pkg"
    pkgbuild --identifier "${{ env.BUNDLE_ID }}.au.pkg" --version ${{ env.VERSION }} --component "${{ env.AU_PATH }}" --install-location "/Library/Audio/Plug-Ins/Components" "packaging/${{ env.PRODUCT_NAME }}.au.pkg"

    pkgbuild --analyze --root "$(dirname "${{ env.STANDALONE_PATH }}")" standalone.plist
    plutil -replace BundleIsRelocatable -bool NO standalone.plist
    pkgbuild --identifier "${{ env.BUNDLE_ID }}.app.pkg" --version ${{ env.VERSION }} --root "$(dirname "${{ env.STANDALONE_PATH }}")" --component-plist standalone.plist --install-location "/Applications" "packaging/${{ env.PRODUCT_NAME }}.app.pkg"

    cd packaging
    envsubst < distribution.xml.template > distribution.xml
    productbuild --resources ./resources --distribution distribution.xml --sign "${{ secrets.DEVELOPER_ID_INSTALLER }}" --timestamp "${{ env.ARTIFACT_NAME }}.pkg"

    xcrun notarytool submit "${{ env.ARTIFACT_NAME }}.pkg" --apple-id ${{ secrets.NOTARIZATION_USERNAME }} --password ${{ secrets.NOTARIZATION_PASSWORD }} --team-id ${{ secrets.TEAM_ID }} --wait
    xcrun stapler staple "${{ env.ARTIFACT_NAME }}.pkg"
```

**Upload .pkg step** (conditional on notarization):
```yaml
- name: Upload pkg
  if: ${{ steps.keychain.outcome == 'success' }}
  uses: actions/upload-artifact@v6
  with:
    name: ${{ env.ARTIFACT_NAME }}.pkg
    path: plugin/packaging/${{ env.ARTIFACT_NAME }}.pkg
```

<task type="auto">
  <name>Task 2: Add GitHub Release job triggered on version tags</name>
  <files>.github/workflows/build_and_test.yml</files>
  <action>
Add a `release` job to the workflow that creates a GitHub Release when a version tag is pushed.

```yaml
release:
  if: contains(github.ref, 'tags/v')
  runs-on: ubuntu-latest
  needs: build_and_test
  permissions:
    contents: write

  steps:
    - name: Download Artifacts
      uses: actions/download-artifact@v7

    - name: Create Release
      uses: softprops/action-gh-release@v2
      with:
        prerelease: true
        files: |
          */*.pkg
```

This job:
1. Only runs when a tag matching `v*` is pushed (e.g., `v0.1.0`)
2. Waits for build_and_test to complete successfully
3. Downloads all artifacts from the build job
4. Creates a GitHub Release with the .pkg attached
5. Marked as prerelease by default — user can manually promote to release

Also ensure the build_and_test job has appropriate `permissions: contents: read` and the release job has `permissions: contents: write`.
