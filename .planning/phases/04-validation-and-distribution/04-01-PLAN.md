  <action>
Create the CI workflow file based on the Pamplejuce template (see RESEARCH.md for full reference).

**Workflow structure:**
- Name: "Build and Validate"
- Triggers: push to main, pull_request, workflow_dispatch
- Concurrency: cancel in-progress builds per branch
- Environment: BUILD_TYPE=Release, BUILD_DIR=Builds, SCCACHE_GHA_ENABLED=true

**macOS-only job** (macos-14 runner):

1. Install deps: `brew install ninja osxutils`
2. Checkout with `submodules: recursive`
3. Cache: `mozilla-actions/sccache-action@v0.0.9`
4. Configure: `cmake -B $BUILD_DIR -DCMAKE_BUILD_TYPE=$BUILD_TYPE -DCMAKE_C_COMPILER_LAUNCHER=sccache -DCMAKE_CXX_COMPILER_LAUNCHER=sccache -G Ninja -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64" .`
5. Build: `cmake --build $BUILD_DIR --config $BUILD_TYPE`
6. Test: `ctest --verbose --output-on-failure` in BUILD_DIR
7. Read .env from CMake (`cat .env >> $GITHUB_ENV`)
8. Set artifact paths (VST3_PATH, AU_PATH, STANDALONE_PATH, ARTIFACT_NAME)
9. Pluginval (VST3): Download pluginval v1.0.3 macOS zip, extract with `7z`, run: `pluginval.app/Contents/MacOS/pluginval --strictness-level 10 --verbose --validate "$VST3_PATH"`
10. Pluginval (AU): Same binary, validate AU_PATH
11. auval: Copy AU to system path, run `auval -v aufx Tnwd Manz` with timeout-minutes: 5
12. Upload artifacts: VST3, AU, Standalone as `$ARTIFACT_NAME` artifact

**Artifact path pattern** (from GitHubENV.cmake):
- `ARTIFACTS_PATH=$BUILD_DIR/${PROJECT_NAME}_artefacts/$BUILD_TYPE`
- `VST3_PATH=$ARTIFACTS_PATH/VST3/${PRODUCT_NAME}.vst3`
- `AU_PATH=$ARTIFACTS_PATH/AU/${PRODUCT_NAME}.component`
- `STANDALONE_PATH=$ARTIFACTS_PATH/Standalone/${PRODUCT_NAME}.app`
- `ARTIFACT_NAME=${PRODUCT_NAME}-${VERSION}-macOS`

**auval step details:**
```yaml
- name: auval
  timeout-minutes: 5
  run: |
    killall -9 AudioComponentRegistrar 2>/dev/null || true
    sudo mkdir -p /Library/Audio/Plug-Ins/Components
    sudo cp -R "${{ env.AU_PATH }}" /Library/Audio/Plug-Ins/Components/
    auval -v aufx Tnwd Manz
```
