Create a placeholder background.png for the macOS pkg installer in plugin/packaging/resources/.

**Background image requirements:**
- Dimensions: 620x418 pixels (standard macOS pkg installer background size)
- Format: PNG, RGB color
- Aesthetic: Manzanita brand — warm, muted, natural. Not corporate, not neon.
- Implementation: Use ImageMagick (available via brew) or Python with Pillow to generate a gradient image programmatically. The gradient should go from a warm terracotta/ochre (#C4723A or similar) at bottom-left to a muted sage/cream (#D4C5A0 or similar) at top-right. This matches the brand palette (terracotta, sage, ochre, cream) and the distribution.xml.template alignment="bottomleft" setting.
- The image should feel intentional — like a brand placeholder, not a test image. A smooth gradient in brand colors is sufficient.

If ImageMagick is not installed, use Python:
```python
from PIL import Image, ImageDraw
img = Image.new('RGB', (620, 418))
# Draw gradient from terracotta to cream
for y in range(418):
    for x in range(620):
        t = (x + y) / (620 + 418)
        r = int(196 + (212 - 196) * t)
        g = int(114 + (197 - 114) * t)
        b = int(58 + (160 - 58) * t)
        img.putpixel((x, y), (r, g, b))
img.save('plugin/packaging/resources/background.png')
```

If neither is available, use `sips` (macOS built-in) to create a solid color image and then manipulate, or write raw bytes with Python's built-in libraries (no pip install needed — use struct/zlib to write a minimal PNG).
